# Changelog

## [1.0] - 2026-10-28

Первый публичный релиз — Пип-Бой-терминал для записи тренировок в зале.

- Стиль Пип-Боя: фосфорно-зелёный терминал, моноширинный шрифт, рамки-панели,
  развёртка ЭЛТ; портретный экран; проверено на слабом железе, minSdk 26
- Программа тренировки приходит JSON-файлом снаружи (нейросеть/скрипт) через
  приватный репозиторий GitHub; на тренировке заполняются только ФАКТ (повторы)
  и ПУЛЬС; таблица подходов №/БЛИНЫ/ВСЕГО/ПЛАН/ФАКТ/ПУЛЬС, вес грифа — на уровне
  упражнения (по умолчанию 20 кг)
- СТАРТ → секундомер → фиксация времени тренировки
- Листание хронологическое: архив (старые → новые), начатая тренировка, план
  («// ПЛАН»); при запуске открывается ближайшая невыполненная; СТАРТ доступен
  на любой странице плана; янтарные подсказки пульса прошлой тренировки
- Своя цифровая панель ввода вместо системной клавиатуры: плановое значение
  черновиком, «ДАЛЕЕ» ведёт по подходам, автозакрытие, страница автопрокручивается
  так, чтобы таблица оставалась видимой
- Передача завершённой тренировки — кнопкой ↑ (момент решает пользователь),
  после передачи страница уходит в архив
- Облако: программы из `programs/pending` встают в план очередью, результаты
  синхронизируются в обе стороны, при конфликте побеждает телефон; история
  возвращается сама после переустановки
- Обмен: при старте, при возврате из фона (не чаще раза в 3 минуты), сразу
  после передачи тренировки и вручную через «⇅ СВЯЗЬ»
- Вход через публичный GitHub App (device flow, доступ только к подключённому
  репозиторию, сессия продлевается сама) или ручной fine-grained PAT; публичный
  репозиторий — предупреждение, обмен не блокируется
- Интерфейс на English / 中文 / Русский, переключение в футере без перезапуска
- Лицензия MIT; релизы публикуются в этом репозитории, исходники разрабатываются
  в приватном
